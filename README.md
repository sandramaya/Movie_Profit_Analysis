
## 🎬 Movie Profit Analysis

## 📌 Project Overview

Movie Profit Analysis is a Data Analytics project focused on exploring movie data and identifying patterns related to production budgets, box-office performance, and profitability.

The project uses Python to clean, analyze, and visualize the dataset to gain meaningful insights.

## 🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Data Analysis
- Data Visualization

## 📊 Analysis Performed

- Analyzed movie production budgets
- Compared domestic and worldwide gross
- Explored movie profitability
- Identified relationships between production budget and revenue
- Created visualizations to understand trends in the data

## 📈 Visualizations

The project includes visualizations such as:

- Scatter plots
- Bar charts
- Distribution charts
- Comparisons between budget and gross revenue

## 🎯 Objective

The main objective of this project is to understand movie profitability through data analysis and visualization, while gaining practical experience with Python and Pandas.

## 📁 Project Files

- `Movie_Profit_Analysis.ipynb` — Jupyter Notebook containing the analysis
- `movie_data.csv` — Dataset used for the analysis
